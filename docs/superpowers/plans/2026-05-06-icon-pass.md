# Icon Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace every emoji-as-icon and unicode-symbol button glyph with a typed `<Icon name="…" size="…" />` component backed by Phosphor, plus add a leading-icon affordance to `<Button>`.

**Architecture:** A single `<Icon>` component owns a const registry that resolves a typed `IconName` union to a Phosphor component, picks pixel size + Phosphor weight from a `size` prop (`sm`/`md`/`lg`), and forwards `currentColor` so consumers tint via Tailwind text classes. The `<Button>` primitive gains optional `iconLeft`/`iconRight` props that render the icon alongside (or in place of) `children`. Each consumer screen migrates in its own commit so the app stays runnable at every checkpoint.

**Tech Stack:** React, TypeScript, Tailwind v4, `@phosphor-icons/react` (MIT), Vitest + Testing Library, Tauri 2.

**Spec:** `docs/superpowers/specs/2026-05-06-icon-pass-design.md`

```tsx
import {
  Microphone,
  WaveformCircle,
  FileText,
  Sparkle,
  Equalizer,
  FloppyDisk,
  Lock,
  WarningCircle,
  Play,
  Pause,
  Stop,
  Trash,
  Plus,
  X,
  Check,
  Pencil,
  CaretRight,
  Folder,
  Waveform,
  Gear,
  Question,
  Info,
  SidebarSimple,
  type IconProps as PhosphorIconProps,
  type IconWeight,
} from "@phosphor-icons/react";

export type IconName =
  | "mic" | "waveform" | "doc-text" | "sparkles" | "equalizer" | "save"
  | "lock" | "warning"
  | "play" | "pause" | "stop" | "trash"
  | "plus" | "x" | "check" | "pencil" | "chevron-right"
  | "folder" | "recording"
  | "gear" | "question" | "info"
  | "sidebar";

export type IconSize = "sm" | "md" | "lg";

const REGISTRY: Record<IconName, React.ComponentType<PhosphorIconProps>> = {
  mic: Microphone,
  waveform: WaveformCircle,
  "doc-text": FileText,
  sparkles: Sparkle,
  equalizer: Equalizer,
  save: FloppyDisk,
  lock: Lock,
  warning: WarningCircle,
  play: Play,
  pause: Pause,
  stop: Stop,
  trash: Trash,
  plus: Plus,
  x: X,
  check: Check,
  pencil: Pencil,
  "chevron-right": CaretRight,
  folder: Folder,
  recording: Waveform,
  gear: Gear,
  question: Question,
  info: Info,
  sidebar: SidebarSimple,
};

const SIZE_PX: Record<IconSize, number> = { sm: 14, md: 20, lg: 32 };
const SIZE_WEIGHT: Record<IconSize, IconWeight> = {
  sm: "bold",
  md: "regular",
  lg: "light",
};

interface Props {
  name: IconName;
  size?: IconSize;
  className?: string;
  "aria-label"?: string;
}

export function Icon({
  name,
  size = "md",
  className,
  "aria-label": ariaLabel,
}: Props) {
  const Component = REGISTRY[name];
  const px = SIZE_PX[size];
  const weight = SIZE_WEIGHT[size];

  if (ariaLabel) {
    return (
      <Component
        size={px}
        weight={weight}
        className={className}
        aria-label={ariaLabel}
      />
    );
  }
  return (
    <Component
      size={px}
      weight={weight}
      className={className}
      aria-hidden
    />
  );
}
```

If Task 1 Step 2 found that any Phosphor name differs (e.g., `Equalizer` not exported), substitute the verified alternative in BOTH the import block and the corresponding `REGISTRY` entry, and update this plan inline so later tasks reference the right name.

```tsx
import { forwardRef } from "react";
import { cn } from "../../lib/cn";
import { Size, sizeClasses, focusClasses } from "./_shared";
import { Icon, type IconName, type IconSize } from "./Icon";

type Variant = "primary" | "secondary" | "destructive" | "ghost";

type Props = React.ButtonHTMLAttributes<HTMLButtonElement> & {
  variant?: Variant;
  size?: Size;
  iconLeft?: IconName;
  iconRight?: IconName;
};

const variantClasses: Record<Variant, string> = {
  primary:
    "bg-accent text-accent-label hover:bg-accent-hover active:bg-accent-pressed",
  secondary:
    "bg-fill-tertiary text-label-primary hover:bg-fill-secondary active:bg-fill-primary",
  destructive:
    "bg-status-error text-white hover:bg-status-error/90 active:bg-status-error/80",
  ghost:
    "text-label-primary hover:bg-fill-tertiary active:bg-fill-secondary",
};

/** Icon size used inside a Button at a given Button size. Icon-only buttons get
 * one step bigger than icon-with-text so a single glyph reads at a comfortable weight. */
function iconSizeForButton(size: Size, iconOnly: boolean): IconSize {
  if (iconOnly) return size === "lg" ? "md" : "sm";
  return "sm";
}

const gapForSize: Record<Size, string> = {
  sm: "gap-1",
  md: "gap-1.5",
  lg: "gap-2",
};

export const Button = forwardRef<HTMLButtonElement, Props>(function Button(
  {
    variant = "secondary",
    size = "md",
    iconLeft,
    iconRight,
    className,
    type = "button",
    children,
    "aria-label": ariaLabel,
    ...rest
  },
  ref,
) {
  const hasChildren =
    children !== undefined &&
    children !== null &&
    children !== false &&
    !(typeof children === "string" && children.length === 0);
  const iconOnly = !hasChildren && (iconLeft !== undefined || iconRight !== undefined);

  if (iconOnly && !ariaLabel && process.env.NODE_ENV !== "production") {
    // eslint-disable-next-line no-console
    console.warn(
      "[Button] icon-only buttons must set aria-label — assistive tech has no text fallback.",
    );
  }

  const iconSize = iconSizeForButton(size, iconOnly);

  return (
    <button
      ref={ref}
      type={type}
      aria-label={ariaLabel}
      className={cn(
        "inline-flex items-center justify-center rounded-md font-medium transition-colors disabled:opacity-50 disabled:cursor-not-allowed",
        sizeClasses(size),
        focusClasses,
        variantClasses[variant],
        hasChildren ? gapForSize[size] : "",
        iconOnly ? "aspect-square px-0" : "",
        className,
      )}
      {...rest}
    >
      {iconLeft && <Icon name={iconLeft} size={iconSize} />}
      {children}
      {iconRight && <Icon name={iconRight} size={iconSize} />}
    </button>
  );
});
```
